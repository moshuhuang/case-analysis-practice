# Capital One Case Interview 官方评分维度(网络检索确认版)

## 结论:官方就是4个维度,不是5个

多个独立信息源(包括对Capital One官方招聘页面的引用)一致确认:**Capital One case interview评估的是以下4个维度，贯穿整场面试的所有阶段，不是只在某一步单独打分。**

---

## 四个官方维度

### 1. Structured Thinking(结构化思维)
- 能否在动手计算之前，把复杂问题拆解成清晰、有条理的组成部分
- 是否用逻辑得出站得住的结论，而不是随意作答
- 关注点:开口前有没有先搭框架，框架是否贴合这道题的类型(不是套模板)

### 2. Quantitative Analysis(定量分析)
- 能否准确读取数据、列出正确的方程、流畅计算
- **这是权重最高的维度之一**——Capital One允许使用计算器，数字刻意设计得"不整齐"(比如$14,237,000这种)，就是为了测试候选人在处理真实、混乱数字时的能力，而不是背模板算干净数字
- 强框架价值有限，真正被评估的是能不能精准执行面试官指向的那个具体计算

### 3. Communication(沟通)
- 能否一边计算一边把思路讲清楚，带着面试官走完整个过程
- 解释是否清晰、有条理，能否让面试官全程跟得上、保持对齐

### 4. Business Judgment(商业判断)
- 结论是否从商业角度站得住脚
- 建议是否现实、贴合真实商业目标，而不是空泛的点子堆砌

---

## 重要澄清:这4个维度 ≠ 之前设计的5个"阶段"

之前评估者agent用的Recap / Clarifying / Framework / Quant / Recommendation，其实是**面试的时间流程(什么时候该做什么)**，跟这次检索到的4个官方维度**不是同一层面的东西**——不冲突，是两套东西该同时用:

| 类型 | 内容 | 作用 |
|---|---|---|
| **流程阶段**(5步) | Recap → Clarifying → Framework → Quant → Recommendation | 决定面试官"什么时候该给什么信息、该等candidate做完什么才能往下走" |
| **评分维度**(4个，本文档) | Structured Thinking / Quantitative Analysis / Communication / Business Judgment | 决定评估者"该从哪几个角度打分"，这4个维度会**贯穿全部5个阶段**，不是每个阶段对应一个维度 |

**举例**:candidate在Recap阶段说漏了关键信息，扣的是Structured Thinking或Communication，不是"Recap维度"本身；candidate在Quant阶段算错，扣的是Quantitative Analysis；candidate在Recommendation阶段没给立场，扣的是Business Judgment。
